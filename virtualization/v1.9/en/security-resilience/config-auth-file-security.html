Configuration and Authentication File Security

To harden your SUSE Virtualization cluster, you must verify and enforce strict file ownership and permission controls across all nodes. System configuration files govern storage, networking, and security secrets, while authentication files (such as keys, certificates, and tokens) establish cluster identity. Restricting access to these critical files prevents non-privileged users or compromised processes from altering system settings, exposing sensitive data, or causing cluster instability.

Test all recommended ownership and mode settings in a non-production environment before production deployment. Enforcing incorrect permissions can disrupt critical cluster services.

Auditing file permissions

Verify the permissions of the files and directories listed in the table using the following commands:

cd <PATH>
ls -l

For example, to verify the permissions of the primary RKE2 (server and agent) configuration files and cluster kubeconfig files, run the following commands:

cd var/lib/rancher/rke2
ls -l

Mitigating insecure file system permissions

  1. Set the correct permissions for insecure files and directories.

    • Files in /etc/rancher/rke2

      cd /etc/rancher/rke2
chmod -R 0600 ./*
chown -R root:root ./*
ls -l

    • Files in /var/lib/rancher/rke2

      cd /var/lib/rancher/rke2
chown root:root ./*
ls -l

    • Subdirectories and files in /var/lib/rancher/rke2/agent

      cd /var/lib/rancher/rke2/agent
chown root:root ./*
chmod 0700 pod-manifests
chmod 0700 etc
find . -maxdepth 1 -type f -name "*.kubeconfig" -exec chmod 0640 {} \;
find . -maxdepth 1 -type f -name "*.crt" -exec chmod 0600 {} \;
find . -maxdepth 1 -type f -name "*.key" -exec chmod 0600 {} \;
ls -l

    • Files in /var/lib/rancher/rke2/bin

      cd /var/lib/rancher/rke2/bin
chown root:root ./*
chmod 0750 ./*
ls -l

    • /var/lib/rancher/rke2/data directory

      cd /var/lib/rancher/rke2
chown root:root data
chmod 0750 data
ls -l

    • Files in /var/lib/rancher/rke2/data

      cd /var/lib/rancher/rke2/data
chown root:root ./*
chmod 0750 ./*
ls -l

    • Files and subdirectories in /var/lib/rancher/rke2/server

      cd /var/lib/rancher/rke2/server
chown root:root ./*
chmod 0700 cred
chmod 0700 db
chmod 0700 tls
chmod 0750 manifests
chmod 0750 logs
chmod 0600 token
ls -l

  2. Edit the RKE2 server configuration file (/etc/rancher/rke2/config.yaml) on all nodes and add the following:

    write-kubeconfig-mode: "0600"

    After updating the configuration file, restart the RKE2 server.

    systemctl restart rke2-server

  3. Set the correct permission for the Container Network Interface file.

    Example:

    cd /var/lib/cni/networks
chmod -R 600 *
ls -l
