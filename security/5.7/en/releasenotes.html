v5.7.x Release Notes

Release Notes for v5.7.x

To receive email notifications of new releases, please subscribe to this SUSE mailing list: https://lists.suse.com/mailman/listinfo/neuvector-updates

5.7.0 November 2026

Notable changes

New Features & Enhancements

  • Image Scanning: Improve error message for image scan (NVSHAS-10316) by @holyspectral in https://github.com/neuvector/neuvector/pull/2601

  • Service Mesh: Match Istio proxymesh traffic against parent workload rules (NVSHAS-10304) by @kyledong-suse in https://github.com/neuvector/neuvector/pull/2679

  • Notifications & API: Support authenticated webhook notifications in NeuVector (issue-2870) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2886

  • Notifications & API: Make password optional in webhook PATCH request (issue-2870) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2927

  • Reporting: Add controller API to send exposure report to syslog by @kyledong-suse in https://github.com/neuvector/neuvector/pull/2922

  • Networking/gRPC: Allow users to adjust gRPC message size by @holyspectral in https://github.com/neuvector/neuvector/pull/2984

  • Logging: Refactor controller and agent pod logs into JSON format by @kyledong-suse in https://github.com/neuvector/neuvector/pull/2932

  • Logging: Refactor monitor and datapath (dp) logs into JSON format by @kyledong-suse in https://github.com/neuvector/neuvector/pull/2938

Security Hardening & Authentication Fixes

  • Security Advisory Fixes:

    • Memory-safety issues in dataplane that could lead to DoS

    • DLP/WAF rule inside every documented validation limit overflows a 2048-byte stack buffer in the enforcer dataplane

    • Neuvector scanner writes registry credentials world-readable to a /tmp file

    • Admission control bypass via ephemeral containers

  • Database: Remediate database queries built from user-controlled sources (code-scanning-95-96-97-98) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2555

  • Sniffer: Prevent command injection in sniffer filter by @kyledong-suse in https://github.com/neuvector/neuvector/pull/2842

  • Encryption: Do not encrypt new data using passwordSymKey by @holyspectral in https://github.com/neuvector/neuvector/pull/2843

  • Authentication: Fix logout bypass via alternate JWT spelling by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2934

  • Authentication: Fix SAML audience confusion allowing cross-SP authentication by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2937

  • Authentication: Fix OIDC authentication failure caused by missing signature algorithms in the allow list by @williamlin-suse in https://github.com/neuvector/neuvector/pull/3048

  • Authentication: Fix crash when flipping auth_by_platform config by @mergify[bot] in https://github.com/neuvector/neuvector/pull/3115

  • API: Limit HTTP read body size when necessary by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2699

  • Sidecars: Remove automatic sidecar exemptions by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2936

Bug Fixes

Runtime, Enforcer, & Datapath

  • Performance/K8s API: Fix NeuVector ConfigMap watch loop causing WAN link saturation (200 Mbps) and kube-apiserver instability (issue-2989) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2990

  • Enforcer: Fix enforcer fanotify self-deadlock by @holyspectral in https://github.com/neuvector/neuvector/pull/2987

  • Enforcer: Improve enforcer connection scaling by @holyspectral in https://github.com/neuvector/neuvector/pull/2805

  • Datapath: Preserve shared pod datapath across container restarts by @kyledong-suse in https://github.com/neuvector/neuvector/pull/2996

  • Kernel/Page Size: Size the netlink dump buffer in probe for kernels with pages over 4K by @brokenlander in https://github.com/neuvector/neuvector/pull/2675

  • Kernel/Page Size: Size the AF_PACKET ring blocks from the runtime page size in datapath by @brokenlander in https://github.com/neuvector/neuvector/pull/2674

  • Process Rules: Inherit parent SID when process is absent (NVSHAS-10273) by @holyspectral in https://github.com/neuvector/neuvector/pull/2785

  • Process Rules: Fix process rules not always working by @holyspectral in https://github.com/neuvector/neuvector/pull/2862

  • Process Rules: Revert process behavior to NOT be the default (issue-2614) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2615

  • Network Rules: Fix pod-service traffic being denied by @holyspectral in https://github.com/neuvector/neuvector/pull/2705 (Note: Reverted in https://github.com/neuvector/neuvector/pull/3036)

CRDs, Federation, & RBAC

  • CRDs: Fix webhook call not being sent when CRD-defined response rules are triggered (issue-2709) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2710

  • CRDs: Prevent users from importing federated groups/policies through CRDs (issue-2727) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2728 & https://github.com/neuvector/neuvector/pull/2736

  • CRDs: Fix duplicate response rules created when importing same-name response rules with changes (issue-2686) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2743

  • CRDs: Allow dry-run admission requests instead of denying them by @brokenlander in https://github.com/neuvector/neuvector/pull/2691

  • Federation: Fix automated federation join failing with controller HA setup by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2866

  • RBAC: Fix missing Role and RoleBinding when autoGenerateCert=false (issue-2597) by @williamlin-suse in https://github.com/neuvector/neuvector/pull/2605
