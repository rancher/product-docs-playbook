アドオン

アドオンは、クラスター起動時にデプロイされるYAMLを含むシークレットを指定します。

表示される:

  • ClusterSpec

フィールド 説明 デフォルト 検証

secretNamespace string

SecretNamespaceはシークレットのネームスペースです。

secretRef string

SecretRefはシークレットの名前です。

AppliedPolicy

AppliedPolicyは、適用されたポリシーの観測された状態を定義します。

表示される:

  • ClusterStatus

フィールド 説明 デフォルト 検証

name string

name は、このクラスターに現在適用されている VirtualClusterPolicy の名前です。

MinLength: 1

priorityClass string

priorityClass は、アクティブな VirtualClusterPolicy によって適用される優先度クラスです。

nodeSelector object (keys:string, values:string)

nodeSelector は、アクティブな VirtualClusterPolicy によって適用されるノードセレクターです。

serverAffinity Affinity

serverAffinity は、アクティブな VirtualClusterPolicy によって適用されるサーバーポッドのアフィニティルールです。
これには、ノードアフィニティルールとポッドアフィニティ/アンチアフィニティルールの両方が含まれます。

agentAffinity Affinity

agentAffinity は、アクティブな VirtualClusterPolicy によって適用されるエージェントポッドのアフィニティルールです。
これには、ノードアフィニティルールとポッドアフィニティ/アンチアフィニティルールの両方が含まれます。

sync SyncConfig

sync は、アクティブな VirtualClusterPolicy によって適用される SyncConfig です。

runtimeClassName string

RuntimeClassName は、virtual または shared モードのクラスターのエージェントおよび
サーバーポッドに対する代替のランタイムクラスを指定します。

podSecurityContext PodSecurityContext

PodSecurityContext は、virtual または shared モードのクラスターのエージェントおよび
サーバーポッドに追加するカスタム SecurityContext を指定します。

securityContext SecurityContext

SecurityContext は、virtual または shared モードのクラスターのエージェントおよび
サーバーコンテナーに追加するカスタムコンテナー SecurityContext を指定します。

hostUsers ブール値

HostUsers は、サーバーポッドおよびエージェントポッドのユーザー名前空間を設定します。
true に設定されている場合、または指定されていない場合、ポッドはホストのユーザー名前空間で実行されます。
false に設定されている場合、ポッド用に新しい userns が作成されます。
このフィールドはアルファレベルであり、UserNamespacesSupport 機能を有効にしたサーバーでのみ有効です。

クラスタ

クラスターはk3kによって管理される仮想Kubernetesクラスターを定義します。 これは、バージョン、ノード構成、ネットワーキングを含む仮想クラスターの望ましい状態を指定します。k3kはこれを使用して、これらの仮想クラスターをプロビジョニングおよび管理します。

表示される:

  • ClusterList

フィールド 説明 デフォルト 検証

apiVersion string

k3k.io/v1beta1

kind string

Cluster

metadata ObjectMeta

`metadata`のフィールドについてはKubernetes APIドキュメントを参照してください。

spec ClusterSpec

Specはクラスターの望ましい状態を定義します。

{ }

status ClusterStatus

Statusは、クラスターの観測された状態を反映します。

{ }

クラスターリスト

クラスターリストはクラスターリソースのリストです。

フィールド 説明 デフォルト 検証

apiVersion string

k3k.io/v1beta1

kind string

ClusterList

metadata ListMeta

`metadata`のフィールドについてはKubernetes APIドキュメントを参照してください。

items Cluster array

ClusterMode

基礎となるタイプ: 文字列

ClusterModeは、クラスターで使用できるプロビジョニングモードです。

サポートされる値: shared、virtual、hcp。

表示される:

  • ClusterSpec

  • VirtualClusterPolicySpec

ClusterPhase

基礎となるタイプ: 文字列

クラスター・フェーズは、クラスターの現在のライフサイクルの高レベルの要約です。

表示される:

  • ClusterStatus

ClusterSpec

クラスター仕様は、仮想Kubernetesクラスターの望ましい状態を定義します。

表示される:

  • Cluster

フィールド 説明 デフォルト 検証

version string

バージョンは、仮想ノードに使用するK3sのバージョンです。
K3sのバージョン管理規則に従う必要があります（例：v1.28.2-k3s1）。
指定されていない場合、ホストノードのKubernetesバージョンが使用されます。

mode ClusterMode

Modeは、クラスターのプロビジョニングモードを指定します。このフィールドは不変です。

shared

Enum: [shared virtual hcp]

servers 整数

サーバーは、サーバー（コントロールプレーン）モードで実行するK3sポッドの数を指定します。
少なくとも1でなければなりません。デフォルトは1です。

1

agents 整数

エージェントは、エージェント（ワーカー）モードで実行するK3sポッドの数を指定します。
0以上でなければなりません。デフォルトは0です。
このフィールドは"shared"モードでは無視されます。

0

clusterCIDR string

ClusterCIDRは、ポッドIPのCIDR範囲です。
"shared"モードでは10.42.0.0/16、"virtual"モードでは10.52.0.0/16がデフォルトです。
このフィールドは不変です。

serviceCIDR string

ServiceCIDRはサービスIPのCIDR範囲です。
"shared"モードでは10.43.0.0/16、"virtual"モードでは10.53.0.0/16がデフォルトです。
このフィールドは不変です。

clusterDNS string

ClusterDNSはCoreDNSサービスのIPアドレスです。
ServiceCIDR範囲内である必要があります。デフォルトは10.43.0.10です。
このフィールドは不変です。

persistence PersistenceConfig

Persistenceはetcdデータを永続化するためのオプションを指定します。
デフォルトは動的永続化で、PersistentVolumeClaimを使用してデータの永続化を提供します。
動的永続化にはデフォルトのStorageClassが必要です。

expose ExposeConfig

ExposeはAPIサーバーを公開するためのオプションを指定します。
デフォルトでは、ClusterIPとしてのみ公開されます。

nodeSelector object (keys:string, values:string)

NodeSelectorはサーバー/エージェントポッドがスケジュールされるノードラベルを指定します。
"shared"モードでは、これもワークロードに適用されます。

priorityClass string

PriorityClassはサーバー/エージェントポッドのpriorityClassNameを指定します。
"shared"モードでは、これもワークロードに適用されます。

tokenSecretRef SecretReference

TokenSecretRefは、ワーカーノードがクラスターに参加するために使用するトークンを含むSecret参照です。
Secretにはデータに「token」フィールドが必要です。

tlsSANs string array

TLSSANsはK3sサーバー証明書のサブジェクト代替名を指定します。

serverArgs string array

ServerArgsはK3sサーバーポッドのための順序付きキー-バリューペアを指定します。
例: ["--tls-san=example.com"]

agentArgs string array

AgentArgsはK3sエージェントポッドのための順序付きキー-バリューペアを指定します。
Example: ["--node-name=my-agent-node"]

serverEnvs EnvVar array

ServerEnvsはサーバーポッドに設定する環境変数のリストを指定します。

agentEnvs EnvVar array

AgentEnvsはエージェントポッドに設定する環境変数のリストを指定します。

addons Addon array

Addonsはクラスター起動時にデプロイする生のYAMLを含むシークレットを指定します。

serverLimit ResourceList

ServerLimitはサーバーノードのリソース制限を指定します。

workerLimit ResourceList

WorkerLimitはエージェントノードのリソース制限を指定します。

serverResources ResourceRequirements

ServerResourcesは、サーバーノードのリソース制限とリクエストを指定します。

workerResources ResourceRequirements

WorkerResourcesは、ワーカーノードのリソース制限とリクエストを指定します。

serverAffinity Affinity

ServerAffinityは、サーバーポッドのアフィニティルールを指定します。
これには、ノードアフィニティルールとポッドアフィニティ/アンチアフィニティルールの両方が含まれます。

agentAffinity Affinity

AgentAffinityは、エージェントポッドのアフィニティルールを指定します。
これには、ノードアフィニティルールとポッドアフィニティ/アンチアフィニティルールの両方が含まれます。

mirrorHostNodes ブール値

MirrorHostNodesはホストクラスターからのノードオブジェクトが
仮想クラスターにミラーリングされるかどうかを制御します。

customCAs CustomCAs

CustomCAsはカスタムCA証明書のための証明書/鍵ペアを指定します。

sync SyncConfig

Syncは仮想クラスターからホストクラスターに同期されるリソースタイプを指定します。

{ }

secretMounts SecretMount array

SecretMountsはサーバーおよびエージェントポッドにマウントするシークレットのリストを指定します。
各エントリは、シークレットとそのポッド内のマウントパスを定義します。

podSecurityContext PodSecurityContext

PodSecurityContext は、virtual または shared モードのクラスターのエージェントおよび
サーバーポッドに追加するカスタム PodSecurityContext を指定します。

securityContext SecurityContext

SecurityContext は、virtual または shared モードのクラスターのエージェントおよび
サーバーコンテナーに追加するカスタムコンテナー SecurityContext を指定します。
このオプションは、virtual モードでデフォルトに設定されている SecurityContext を上書きします。

runtimeClassName string

RuntimeClassName は、virtual または shared モードのクラスターのエージェントおよび
サーバーポッドに対する代替のランタイムクラスを指定します。

hostUsers ブール値

HostUsers は、サーバーポッドおよびエージェントポッドのユーザー名前空間を設定します。
true に設定されている場合、または指定されていない場合、ポッドはホストのユーザー名前空間で実行されます。
false に設定されている場合、ポッド用に新しい userns が作成されます。
このフィールドはアルファレベルであり、UserNamespacesSupport 機能を有効にしたサーバーでのみ有効です。

ClusterStatus

ClusterStatusは、クラスターの観測された状態を反映します。

表示される:

  • Cluster

フィールド 説明 デフォルト 検証

hostVersion string

HostVersionは、ホストノードのKubernetesバージョンです。

clusterCIDR string

ClusterCIDRは、ポッドIPのCIDR範囲です。

serviceCIDR string

ServiceCIDRはサービスIPのCIDR範囲です。

clusterDNS string

ClusterDNSはCoreDNSサービスのIPアドレスです。

tlsSANs string array

TLSSANsはK3sサーバー証明書のサブジェクト代替名を指定します。

policyName string

PolicyNameは、仮想クラスターにバインドされた仮想クラスターポリシー名を指定します。

policy AppliedPolicy

policy は、このクラスターに適用されたポリシーのステータスを表します。
このフィールドは VirtualClusterPolicy コントローラーによって設定されます。

kubeletPort 整数

KubeletPortは、shared モードで k3k-kubelet が使用するポートを指定します。

conditions Condition array

Conditionsは、クラスターに設定された個々の条件です。

phase ClusterPhase

Phaseは、クラスターの現在のライフサイクル状態の概要です。

Unknown

Enum: [Pending Provisioning Ready Failed Terminating Unknown]

- ServiceAccountToken署名キーの場合：tls.key.

defaultMode 整数

defaultModeは任意のフィールドで、作成されたファイルのパーミッションを設定するためのモードビットを指定します。
値は、0000から0777の間の8進数値、または0から511の間の10進数値でなければなりません。
YAMLでは8進数値と10進数値の両方が受け入れられますが、JSONでは10進数値が要求されます。
これはモードビットのための指定です。デフォルトは0644です。
パス内のディレクトリはこの設定の影響を受けません。
これは、ファイルに影響を与える他のオプションと競合する可能性があります。
モードはfsGroupなどの他のファイルモード設定と競合する場合があり、その結果、他のモードビットが設定されることもあります。

ボリュームマウントの名前として使用される Secret マウントボリュームの名前です。
空の場合は、代わりに Secret の名前が使用されます。

MaxLength: 63
MinLength: 1
Pattern: ^[a-z0-9]([-a-z0-9]*[a-z0-9])?$

mountPath string

MountPathは、サーバーおよびエージェントポッド内のパスです。
シークレットの内容がマウントされます。

SubPathは、ルートの代わりにマウントするためのシークレット内のオプションのパスです。
指定された場合、シークレットから指定されたキーのみがファイルとしてマウントされます。
MountPathで、親ディレクトリは書き込み可能のままです。
