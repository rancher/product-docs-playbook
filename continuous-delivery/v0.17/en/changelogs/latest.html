v0.17.0

Breaking Changes

Policy and Service Account Permissions

  • Disable Helm namespace creation by default when a Policy requires a service account; set allowNamespaceCreation to true to permit it (GHSA-m93g-8438-2cgg) by @p-se in #5351

  • Require deployment service account permissions for copying downstream Secrets and ConfigMaps (GHSA-q9v4-358v-r8q5) by @p-se in #5787

  • Restrict downstreamResources through the new Policy field allowedDownstreamResources; when a Policy requires a service account and the list is empty, no Secrets or ConfigMaps are copied by @p-se in #6100

  • Manage namespace labels and annotations with server-side apply, preserving metadata owned by other managers; deployment service accounts need patch instead of update permission on namespaces #4564 by @p-se in #5460

Cluster Registration

  • Bind agent-initiated cluster registrations to their registration token; the allowClusterRegistrationTokenChange Helm value permits token changes (GHSA-gx8v-2929-9q95) by @thardeck in #5950

  • Require kubeconfig Secrets referenced across namespaces to carry the fleet.cattle.io/kubeconfig-referenceable-from label naming the Cluster namespace; the allowUnlabeledKubeConfigSecretNamespaces Helm value accepts unlabeled Secrets in the well-known namespaces (GHSA-qfmw-gw96-ffcr) by @thardeck in #5968

Templating and Helm Values

  • Restrict Helm valuesFiles paths to the checkout root (GHSA-wpfm-r97v-3j4h) by @thardeck in #5775

  • Remove getHostByName from template functions (GHSA-x9m6-xcjr-hpjp) by @thardeck in #5606

Deprecation Notice

  • GitRepoRestriction is deprecated in favor of Policy; removal is planned for Rancher v2.17.0 #5306 by @d3flex in #5347

  • Unauthenticated webhook calls are now deprecated. The SUSE® Rancher Prime Continuous Delivery webhook server warns about such calls when receiving them. See the documentation for configuring a webhook secret. Issue #5298 resolved by @d3flex in #5419

Future Deprecation Notice

  • imagescan will be deprecated in v0.18, to be then removed in v0.19.

  • keepResources will be deprecated in v0.18, in favor of a new option. See #5941 for more context.

Notable Changes

  • Label deployed resources with their Fleet source #5262 by @d3flex in #5834

  • Report bundle deployment failures and recovery as Kubernetes events #4455 by @0xavi0 in #5515
